模板管理：生成、下载、导入、改模板

1. 生成模板

给一张样表（CSV/JSON），或直接填字段名（一行一个，或逗号分隔），生成专用模板草稿。

2. 改模板（JSON 文本编辑＋校验）

把模板 JSON 粘贴进来直接改：fields 里每行的 sourceColumn 改成你表里的列名；categories 改分类；specDims 改维名与取值；freightTemplates 改成你后台已建好的运费模板。改完先校验，再建配置。
