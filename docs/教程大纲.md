# 教程大纲（拟稿，非终稿）

终稿等 Sam 中途测试反馈后做。两份：图文版随包走，短录屏放商品页（分段录）。

1. 这是什么：半自动上新 + 批量上下架，适用三种场景（通用模板 / WANDER 本店 / 无后台文件版），平台店铺不适用。
2. 准备：对方商城导出的商品表（CSV 或 JSON）、素材包（清单 + 图片），图片命名规则。
3. 第一次：导入模板 → 程序提议映射 → 人核对一次保存 → 之后复用。
4. 每次上新：拖包 → 试跑看报告 → 确认 → 看草稿 → 后台审核上架。
5. 字段说明：共通必填（缺了报错）、规格 0-3 维、扩展袋（目标无字段时只提醒）。
6. 图片角色：主图/详情图/规格图/说明图，文件名标记规则。
7. 上下架：批量设定、售罄开关、锁定、单次上限、总开关、回滚。
8. 使用范围与注意事项：只认三种场景；轮询不小于 5 分钟；时间存 UTC、显示北京时间；封闭系统只能出文件；价格单位（元/分）识别规则；规格值不要含 `/`。
9. 常见问题：映射猜错怎么办、试跑报错怎么办、草稿与上架的区别。
