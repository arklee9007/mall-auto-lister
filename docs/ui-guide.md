# 界面版使用指南（v1.3.0）

自动化插件的本地网页界面：不用敲终端，在浏览器里点一点就能走完“对字段 → 试跑 → 看草稿和排程”三步。服务器只在本机运行，数据不上传到任何地方。

## 启动

准备：电脑上装好 Node.js v20.19 或更高（命令行输入 `node --version` 能打出版本号就是装好了；打不出先装 Node，下载地址见 Node.js 官网，装 LTS 版即可）。

- Windows：双击 `start-ui.bat`，会自动打开浏览器到 `http://127.0.0.1:18771/`。关闭名为 automation-ui 的窗口即停止服务。
- macOS / Linux：终端里进到本目录，跑 `sh start-ui.sh`（或先 `chmod +x start-ui.sh` 再 `./start-ui.sh`），会自动打开浏览器。按 Ctrl+C 停止。
- 手动启动：`node bin/server.mjs`（默认端口 18771）。改端口：`node bin/server.mjs --port 18800`，或设环境变量 `PORT=18800 node bin/server.mjs`。启动后自己打开浏览器访问 `http://127.0.0.1:18771/`（端口换成你改的）。
- 端口被占：换一个端口启动即可（见上）。服务只监听本机（127.0.0.1），局域网其他电脑打不开，这是故意的。

## 三步怎么用

### 一、对字段

1. 上传对方店铺样表（CSV 或 JSON；Excel 请先另存为 CSV 或 JSON 再传），点“扫描样表”。
2. 程序按表头提议映射：每行目标字段对应来源列，状态分 auto（可直接用）／review（须人确认）／missing（缺失）。逐行核对：来源列对不对、规格维认得对不对。重点确认价格单位是元还是分（默认按元）。
3. 填配置名、选目标，点“保存配置”。必填 6 项（商品名、分类、价格、库存、主图、运费方式）缺了会保存失败并点名。
4. 已有专用模板 JSON 文件的，用“从模板建配置”直接上传建配置。
5. 配置列表里可查看、编辑、删除。编辑时映射、价格单位、运费模板都能改，保存前程序会校验，不通过会说明原因。

### 二、试跑

1. 选配置，上传商品清单（CSV 或 JSON），选图片（只传文件名，不上传图片内容；图片按文件名归角色）。
2. 有专用模板的可以再选一个模板文件，导入时用它现场生成配置，不改存量配置。
3. 点“开始试跑”，看报告：解析几件商品、错误几条、提醒几条（解析提醒与适配提醒分开数）、运费映射、首件翻译结果。
4. 结论只有两种：无错误就是“只解析、只出报告，未写入任何目标（零写入）”；有错误就是“拒绝导入”，先改清单再跑。
5. 没数据练手就点“填入示例”：用内置演示数据（3 件商品的清单与图片文件名）。没有配置时点“自动建演示配置（测试店）”。

### 三、看草稿和排程

- 模拟导入：用试跑页选好的配置与清单，点“模拟导入，看草稿”。草稿 0 → 3 件，全部为 stage=pool、review=pending、onShelf=false（草稿态，不直接上架）。目标是抖音／淘宝／小红书／Shopify／WooCommerce／有赞／SHOPLINE 时会明确拒绝，并说明接口未接通——这是正常的，不是故障。
- 文件包：点“生成文件包”，下载标准商品表.csv 与图片改名计划.json（无后台场景用）。
- 上下架计划：填状态 JSON 与规则 JSON（规则时间可写可读时间，如 `"shelfAt": "2026-11-14T13:20"`，就是配置时区的墙上时间），点“看计划”或“模拟执行与回滚”。“填入示例状态与规则”用内置演示数据。模拟执行后会回滚并显示“回滚一致：是／否”。

### 模板管理

- 生成模板：给一张样表，或直接填字段名，生成专用模板草稿（JSON），可下载。生成后草稿会自动填入下方编辑框。
- 改模板：在编辑框里直接改 JSON（fields 里每行的 sourceColumn 改成你表里的列名；categories 改分类；specDims 改维名与取值；freightTemplates 改成你后台已建好的运费模板），点“校验模板”，通过后再填配置名“用这个模板建配置”。

### 参考

- 平台字段映射表：抖音／淘宝／小红书的必填字段、品类扩展字段、规格维、图片要求、上下架状态。
- 自建店字段映射表：Shopify／WooCommerce／有赞／SHOPLINE 的同类内容。

### 接入流程

- 自有后台（通用模板／WANDER／文件版）与第三方（抖音／淘宝／小红书／Shopify／WooCommerce／有赞／SHOPLINE）分开写，每家三段：咱们这边已做好的部分、商家要准备的东西、还缺的第三方开口（以及接通后的步骤）。内容与 `docs/接入流程.md` 一致，数据直接取各适配器的定义。

## 常见问题

- **配置保存在哪？** `profiles/` 目录下一个配置一个 `.json` 文件，界面里改完保存就是改这个文件；直接用记事本改也行，改完界面刷新就能看到。
- **图片为什么只传文件名？** 引擎只按文件名归角色（主图／详情图／规格图／说明图），不读图片内容，所以浏览器只把文件名发给服务器，图片本身不用上传。
- **Excel 表格传不上去？** 模板与清单只认 CSV 与 JSON，Excel（.xlsx/.xls）会明确拒绝。请在 Excel 里另存为 CSV 再传。
- **试跑报“运费方式未填”？** 清单里运费格留空会直接报错。填包邮、固定运费金额，或买家后台已建好的运费模板名；工具不自动编默认值。
- **抖音目标点“模拟导入”被拒绝？** 正常的：抖音／淘宝／小红书与四家自建店的写入口未接通，程序明确拒绝，不返回假成功。先用 `dry-run` 看映射，等接口接通后再导入。接通要准备什么见“接入流程”页。
- **端口 18771 打不开？** 先看终端／窗口里服务器是不是还在跑；再看是不是端口被占了，换个端口启动（见上）。
- **界面是英文吗？** 全是简体中文。
- **数据会上传吗？** 不会。服务器只监听本机，文件内容只在本机内存里解析，配置存在本机 `profiles/`。
